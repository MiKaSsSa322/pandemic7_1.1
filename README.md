# Pandemic: 7 Minutes (Minecraft 1.20.1, Forge 47.2.0, Java 17)

Каждые 7 минут игрок получает новую случайную болезнь (100 штук). Таймер и болезни у каждого игрока свои,
хранятся в данных игрока (переживают выход из мира) и синхронизируются с клиентом.

## Как получить .jar
### Вариант A — без установки (GitHub)
1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки (вместе с `.github`).
2. Вкладка **Actions** → **Build mod** → дождись зелёной галочки.
3. Внутри запуска скачай артефакт `pandemic7-jar` → в нём `pandemic7-1.1.0.jar`.

### Вариант B — локально
1. Установи JDK 17 и Gradle 8.1.1+.
2. В папке проекта: `gradle build`
3. Готовый файл: `build/libs/pandemic7-1.1.0.jar` → положи в `mods/` (клиент и сервер).

## Команды
- `/pandemic list` — ваши болезни с описаниями; `/pandemic catalog` — все 50
- (оп) `/pandemic add <1-50>`, `/pandemic clear`, `/pandemic timer <секунды>` — для теста

## Клавиши (меняются в Настройки → Управление → Pandemic)
- **H** — скрыть/показать список болезней (таймер остаётся)
- **J** — скрыть/показать весь HUD мода
